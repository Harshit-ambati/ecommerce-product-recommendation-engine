# E-Commerce Product Recommendation Engine

AI & Machine Learning project assessment for Algions AI Labs.

## Status

Implemented and evaluated on synthetic data: three recommenders, saved-artifact inference, interactive demo, tests and reports. Local demo only; no public deployment or recorded submission video yet.

## Implemented scope

- Reproducible licensed or synthetic product and interaction data.
- Exploratory data analysis and data quality checks.
- Popularity baseline, content-based recommendations, and collaborative filtering.
- Chronological training, validation, and held-out test evaluation without future leakage.
- Precision@10, Recall@10, NDCG@10, catalog coverage, and cold-start analysis.
- An inference interface that loads saved artifacts and explains recommendations.
- Reproducibility tests, setup instructions, technical report, and demo recording script.

## Quick start

Tested with Python 3.14.2. Run from the repository root (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m recommender.pipeline
python -m pytest -q
python -m recommender.predict --user U0000 --k 10
python -m streamlit run app.py
```

Open the URL printed by Streamlit. On a fresh deployment, the app runs the seeded training pipeline once to create its model and reports before showing recommendations. The first load can take a minute; later reruns use the saved artifact. If PowerShell activation is disabled, replace `python` with `.venv\Scripts\python.exe`. On macOS/Linux activate with `source .venv/bin/activate`. Direct dependencies are pinned; transitive dependencies are not fully locked.

The pipeline generates data in `data/raw`, chronological splits in `data/processed`, a model in `artifacts/recommender.pkl`, and evidence in `reports`. Data and artifacts are ignored by Git and regenerated from seed 42. Load only trusted, locally generated pickle artifacts. Use `--seed 42` explicitly to reproduce the reported experiment.

## Held-out results

| Method | Precision@10 | Recall@10 | NDCG@10 | Catalog coverage |
|---|---:|---:|---:|---:|
| Popularity | 0.0274 | 0.0791 | 0.0550 | 11.11% |
| Content | 0.0416 | 0.1151 | 0.0836 | 98.61% |
| Collaborative | 0.0427 | 0.1195 | 0.0894 | 38.06% |

Collaborative filtering was selected on validation NDCG before test evaluation. These are single-seed synthetic results, not evidence of commercial performance. The demo uses the artifact frozen at the test cutoff. Unknown shoppers receive popularity recommendations.

## Project map

- `recommender/data.py`: synthetic generator and schema validation.
- `recommender/model.py`: recommenders, explanations, serialization.
- `recommender/evaluation.py`: full-catalog ranking metrics and segment audits.
- `recommender/pipeline.py`: generation, training, selection, evaluation and reporting.
- `recommender/predict.py`: inference CLI; `app.py`: interactive interface.
- `tests/`: leakage, preprocessing, ranking, serialization and UI tests.
- [Technical report](docs/technical-report.md): methods, diagram, results and limitations.
- [Data card](docs/data-card.md): provenance, schema and assumptions.
- [Demo script](docs/demo-script.md): recording and submission checklist.
- `reports/`: actual numerical outputs, data hashes and error cases.
